# Hermes Island 使用与验证

当前分支以 **上游 v2.8-rc.2** 为基线，面向 Apple Silicon / macOS 27。
应用保留音乐、电池、系统浮层、镜像、通知与暂存区。日历和提醒事项恢复为原生 EventKit；不再配置 Vikunja REST。
Hermes 构建关闭上游 Sparkle，使用本分支 Actions 的 Ad-hoc DMG / ZIP 更新。

## 配置 Hermes

在设置的 **Hermes** 页面填写：

- **接口地址**：完整 OpenAI Chat Completions 流式地址，例如 `https://host/v1/chat/completions`。
- **模型**：服务实际支持的模型 ID。
- **API 密钥**：原始 token；应用添加 Bearer 前缀。无需认证时可留空。
- **Cloudflare Access**：Client ID 与 Secret 成对填写，分别发送为 `CF-Access-Client-Id`、`CF-Access-Client-Secret`。
- **自定义请求头**：按名称和值添加；请求头中的密钥也保存在钥匙串。

连接信息初始留空，由使用者自行配置；密钥保存在钥匙串中，不写入日志或仓库。
保存配置后新请求使用新配置，应用不会代为配置 Hermes 服务。
发送前先检查配置、便签和附件；检查失败保留草稿。请求开始后，问题立即进入会话，
输入栏清空并可继续写下一条。等待首字时显示“正在思考”，失败或停止保留该轮内容并可重试。
后续请求只包含最近 5 轮已成功完成的问答（最多 10 条上下文消息），同时受总文本大小限制；重试不会重复增加同一条用户消息。
收起灵动岛或切换标签后，请求继续在后台执行；重新打开时显示当前进度或完整结果。
只有主动停止、清空或锁屏才取消请求。最后一个抽屉关闭且请求结束后，闲置 15 分钟清空内存中的会话。
图片编码只属于当前请求，不进入历史上下文；成功后删除临时图片，停止或失败时仅保留源文件用于重试，清空或闲置清理时删除。

## 本地 Markdown 与宽度

在 **本地便签** 选择一个已有 `.md` 文件，文件名不限，无需选择文件夹。
旧版目录授权不会猜测或自动绑定 `Today.md`。原文件和旧设置均保留。

- 输入框旁的“便签”开关控制后续发送是否附加绑定 Markdown，开启后显示文件名；每次发送重新读取，默认开启，点击 Chip 的叉号可关闭。关闭开关不修改先前已经发送的历史内容，清空会话可移除旧上下文。
- 点击输入框旁的回形针，逐项选择暂存区中的文件和图片；默认不勾选，选中后用托盘图标显示 Chip。支持多选，再次点击或 Chip 叉号取消引用，不删除暂存区原文件。选中的文件在后续发送中会重新读取，清空会话后清除选择。
- 同一个回形针面板支持搜索并选择剪贴板历史中的文本或图片。选择后生成可移除附件，仅在点击发送时提交；不改写系统剪贴板、不触发粘贴、不自动发送。
- 直接拖入 Hermes 的附件仅用于该次发送；与暂存区同路径文件去重。两者合计最多 6 个文件，超限或任何读取失败都会保留草稿并提示。
- 文本文件需为 UTF-8（每个最多 64 KB），文本附件与便签随该轮文字保留到最近 5 轮历史中；总历史仍有 256 KB 上限，超限会提前淘汰旧轮。图片经下采样发送，编码不保留在历史里；放在暂存区的原图在后续请求中会重新附加。
- 暂存区链接不会自动抓取网页，PDF、Office、压缩包等二进制文件尚不支持作为文本附件。
- 发送时重新读取文件；读取失败保留输入并显示错误。
- **保存到便签** 按钮是唯一写入入口，将回答作为复选任务追加到同一文件，多行内容缩进。生成完成、收起或切换标签都不会自动写入。
- 写入使用文件协调、版本复查与原子替换，保留 UTF-8 BOM、既有内容和换行风格。
- 设置页或抽屉宽度弹出菜单可调整标准/展宽宽度；按显示器可用空间限制尺寸。

在 **灵动岛** 设置开启 **记住上一个标签页** 后，普通悬停与打开快捷键恢复上次关闭的标签，
并在重启后保留。此选项优先于“暂存区有文件时默认打开”；剪贴板专用快捷键与拖入附件仍打开对应标签。

监听文件和可访问的父目录，并使用 NSFilePresenter。单文件沙盒授权若不允许访问父目录，
无法保证收到其他同步软件所有未协调的原子替换通知；实际发送仍重新读取，不复用旧上下文。

## 日历与提醒事项

在系统设置中授权当前安装版的日历和提醒事项访问，在应用的 **日历** 页面选择系统列表。
应用读取 EventKit 已能看到的数据；第三方服务与 macOS 账户的同步由使用者自行完成。
不要求 Hermes 或 Vikunja 地址，也不再强制排除远端 Project 3。

## 剪贴板

首次在 **剪贴板** 设置中主动启用记录，并按 macOS 提示允许剪贴板读取。
默认全局快捷键是 **⌘⇧V**，可在 **快捷方式** 页面修改，避免与 Raycast 等工具冲突。
鼠标展开后也可直接选择剪贴板标签。快捷键打开时保持展开并聚焦搜索，不要求移动鼠标。

- 上下键选择；Enter 或单击项目粘贴到原输入框；⌘Enter 仅复制；Esc 关闭。
- 文字、链接、富文本与图片保留本地历史，支持搜索、收藏、删除。
- 图片保存 PNG/TIFF/JPEG 等实际原始表示，包含可用透明通道；缩略图仅用于预览。
- 从 Finder 复制图片文件属于文件引用，与直接复制图像不同；原文件失效或授权失效时显示错误。
- 记录按内容去重；默认 200 条、7 天、256 MB，可在设置中调整。收藏受保护，空间不足会提示。
- 跳过机密、临时、自动生成及自身复制标记；支持排除应用；锁屏暂停采集。
- 所有历史仅存本机，不自动发送到 Hermes，不访问网络。

自动粘贴分别检查执行进程的控制/辅助功能授权与按键发送权限；启用记录时另请求读取剪贴板。
缺少权限时弹出对应授权或系统设置入口，失败会明确说明是权限、原输入位置变化还是按键投递问题。
面板取得键盘前保存原应用、窗口和输入控件引用，不读取输入内容；关闭面板后恢复该控件，
再次复查目标与锁屏状态，由非沙盒 XPC helper 在目标位于前台时通过系统会话发送一次粘贴按键。
授权后需返回目标输入框并重新打开剪贴板，不会把授权前的旧操作自动补发。
系统不回报目标应用是否接受了粘贴，因此仍需实际应用验收。
Ad-hoc 更新可能要求重新授权；仅复制历史项目不依赖自动粘贴权限。

## 自动检查

```sh
swift run --package-path Packages/IslandCore IslandCoreChecks
python3 .github/scripts/test_island_stream.py
python3 .github/scripts/test_hermes_submission.py
python3 .github/scripts/test_shelf_context.py
python3 .github/scripts/test_clipboard_paste.py
python3 .github/scripts/test_clipboard_alert.py
python3 .github/scripts/test_clipboard_native_event.py
python3 .github/scripts/test_workspace_animation.py
python3 .github/scripts/test_island_components.py
python3 .github/scripts/check_chinese_localization.py
python3 -m unittest discover -s .github/scripts/tests -q
```

核心夹具覆盖 SSE UTF-8 分片、取消、会话淘汰、任意文件名、BOM/CRLF、并发追加、同步原子替换、
图片下采样，以及剪贴板原始图片/透明度、重启恢复、多条项目顺序、去重、并发写入、配额与过滤。
中文审计覆盖应用拥有的源字符串与资源；保留品牌、URL、设备名称、用户内容、服务返回内容。
暂存区夹具直接编译生产 provider 解析、Bookmark 与 ShelfStateViewModel，验证文件 URL、中文空格路径、仅提供数据的图片、引用排除和错误呈现；不读取用户暂存区。
提交夹具核对序列化 HTTP 请求中的默认便签与暂存区文件文本及追问历史，并直接编译生产 HermesStore，以隔离的流与文件替身验证异步草稿生命周期、后台持续生成、隐藏时锁屏取消、闲置清理、5 轮上下文和图片释放。
生产会话路由由注入的记录器检查，不实际发送系统会话事件。原生粘贴夹具使用无窗口的沙盒测试应用、生产 helper 与隔离 PID 接收器；
运行环境没有既有按键发送权限时记录 SKIP，不自动申请授权。收到隔离定向事件不代表生产会话路线或真实编辑器已接受粘贴，详见 [实现研究](clipboard-research.md)。
动画夹具在所有屏幕之外采样真实布局与渲染像素，检查轮廓、阴影、输入栏位置和透明区域命中范围。

Actions 使用 Xcode 27.1 / ARM64，校验嵌套签名、架构、可执行权限，并运行成品启动/XPC 只读检查，
再生成并验证 DMG。启动检查不读取真实剪贴板、不发起 Hermes 请求、不申请权限。

## 用户验收

界面操作和权限由使用者自行测试：中文输入、悬停和快捷键、多屏展宽、锁屏取消、图片粘贴、
Markdown 保存、系统日历提醒事项及原有功能。真实 Hermes 连接、同步软件行为和常驻内存/CPU
不以核心夹具或成功编译代替；在相同使用场景下测量后再比较。
